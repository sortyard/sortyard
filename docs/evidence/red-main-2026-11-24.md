`sortyard` on aks-obs-01, Argo Application `sortyard-kernel`), watching the lane `canary` only
(`noncelogic/sortyard-canary`). Three drills turned that repository's `main` red on purpose. The

## The drill

`main`: on push, and by hand. It runs `./health.sh`, and that script fails until
`notes/health.txt` holds an expected line. The required pull-request check `check` does not run
it, so the change merged and `main` went red. Drills 2 and 3 changed the expected line (pull
requests #6 and #8). In each drill a second red run was started by hand (`workflow_dispatch`) once
the item was open.

## Drill 1 (on `7d5b969`): one incident, two items

What happened, in order:

1. At 22:09:58 the observer admitted item `red-main-686878375c8c-45498206917`.
2. At 22:11:02 it recorded run 45498221481 on that item as evidence. The item's timeline shows
   the move building → decision (request `resume`) → building.
3. The item went building → checking → reviewing → merging → merged (22:12:12).

**The defect.** At 22:12:38 the merge's run had not finished. The newest *finished* run was the

`red-main-686878375c8c-45498221481`. Its build found nothing to change (`no-change` twice). At
22:13:10 it was withdrawn as moot, after the merge's run went green. It opened no pull request.

The fix, in #42: the verdict comes from the newest run, in progress included.

## What this shows against the spec

- **A red default-branch run is answered after one cycle.** In every drill a kernel item was
  admitted within 35 s of the run failing.
- **Two open triage items for one red workflow never existed.** In drills 1 and 2, though, a
  second item followed a merged one for the same incident. Those were the defects fixed in #42
  and #43. Each extra item ended as `withdrawn` (moot), with no pull request.
- **A later red run while the item is open is evidence, not an item.** This held in all three
  drills: a request whose answer is `resume`, on the item's timeline, after which the item
  carried on building.
- **A green run ends the incident.** The fix merged, and the run of the merge was green. In
  drills 1 and 2 a green run withdrew an item that had not merged.
